# Changelog

## V1 (this package)
- First community verification package for R2 (final) and the R3 alternative packages.
- Adds the R3 packages: (C) and (D) with solutions and challenge configurations, (A) and (B) as statement files only; the delivered (C) and (D) solution files carry a one-line import fix (finding 7).
- Adds the public verification entry point (`VERIFY.sh`, `VERIFY.ps1`), the source-binding check, the axiom/theorem-binding enumerator, the route-coverage check and the control runner, all using only the Python standard library and public tools.
- Adds controls for R3's (C) and (D): `sorry` solution, statement without F5's integrability, weakened force bound.
- `VERIFY.sh` raises and checks the open-file limit (finding 8).
- Mathematical inputs are unchanged from the earlier private R2 package apart from the R3 additions: the project tree is the authoritative source archive byte for byte plus the eight R3 files.
