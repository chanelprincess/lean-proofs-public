# Known limits

- **Tested environment**: two runs on one Ubuntu 24.04.5 x86_64 machine with resident Lean, Rust, Go, gcc and git, and an already populated Mathlib cache for the pinned revision. First-time Mathlib download and clean-machine restoration were not tested. Windows and macOS were not tested. No offline restoration is provided.
- **`scripts/reproduce.sh` was executed once end to end, on one machine** (run `s437.pubentry.run4`, archive v2, 1,834 s, exit 0). Omniscient extracted the archive and ran the script itself, not a reconstruction of its commands, inside an isolated systemd user unit (private /tmp; home directory hidden except `.cache`, `.elan`, `.rustup` and the work directory; toolchains read-only; no new privileges; Unix sockets blocked; network allowed for the declared git, crate and Go-module retrievals), against the already populated Mathlib cache (17,655 entries before and after; none added or removed). The runner checked from raw output, not from the script's own PASS line: exit status 0; steps 1-14 announced in order; the four controls returned exit codes 0, 1, 0, 1; Comparator output contained 3 "Your solution is okay!", 2 constant-kind-mismatch rejections, 2 nanoda and 3 Lean-kernel acceptances; both declarations were exported; the independent axiom probe listed only `propext`, `Classical.choice`, `Quot.sound`; `lake-manifest.json` was unchanged; all 11 dependency checkouts matched the manifest revisions; the three tools were restored and 610 project `.olean` files were created during the run. **It was one execution**, and an earlier attempt found a defect (the script ran its steps from the caller's directory), fixed before this run (archive v1 to v2). This archive (v3) differs from the executed v2 only in documentation text: `scripts/reproduce.sh` and `project/` are byte-identical to v2.
- **Target closure only**: the run compiles the closure of the two checked declarations plus the challenge module, not all 2,659 Lean modules in the repository.
- **Repeatable, not byte-identical**: `nanoda_bin` and `landrun` rebuilt in the two runs differed in length. Only the verification result is claimed to repeat.
- **Correspondence**: the comparison of the formal statements with the official Clay text is the packager's analysis, not an independent review. For (D) it depends on reading the Clay erratum as requiring periodic pressure. Whether (D) also holds without that requirement is open.
- **Informal paper**: not independently refereed in these records.
- **Scope of the theorems**: forced Navier-Stokes alternatives (C) and (D) only; not the unforced alternatives (A) and (B); nothing about the Euler results in the same repository.
- **Not claimed**: Clay acceptance, a prize, or any institutional recognition.
